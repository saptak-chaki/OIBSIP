# Oasis Infobyte Internship - Web Development Task

## 🌐 Landing Page (Task 1)

This project is a visually polished and responsive static landing page built as part of the Oasis Infobyte Web Development Internship (OIBSIP).

### 🚀 Features
- **Fixed/Sticky Navigation Bar:** Easy access to key sections.
- **Hero Section:** Features a catchy headline, subheadline, and Call-To-Action (CTA) button.
- **Content Sections:** Includes dedicated sections for Features/About and Testimonials.
- **Footer:** Contains placeholder contact and social links.
- **Fully Responsive:** Built using CSS Flexbox/Grid to ensure seamless viewing across mobile, tablet, and desktop screens.

### 🛠️ Tech Stack
- **HTML5**
- **CSS3**

### 💻 How to View
1. Clone the repository: `git clone https://github.com/your-username/OIBSIP.git`
2. Navigate to the folder: `OIBSIP/WebDev-L1-LandingPage/`
3. Open `index.html` in any web browser.
