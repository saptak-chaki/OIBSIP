# OIBSIP — Cyber Security Internship Tasks

This repository pack contains four task folders based on the Oasis Infobyte task guide.

## Included tasks
1. `Task-1-Nmap-Scanning/` — Nmap commands, result template, and README.
2. `Task-2-UFW-Firewall/` — UFW configuration script and README.
3. `Task-4-Network-Security-Threats/` — completed research report.
4. `Task-5-Social-Engineering/` — completed research report.

## Important
- Only scan devices you own or have explicit written permission to assess.
- Configure UFW only on a test VM or machine where you understand the impact of firewall rules.
- The Nmap results and UFW verification are intentionally left for you to run and capture. Do not submit invented scan output or screenshots.
- Practical tasks need your own terminal screenshots and genuine output.
